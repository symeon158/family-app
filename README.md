# 🎓 Ο Ηλεκτρονικός Δάσκαλος — Έκδοση με τα σχολικά βιβλία

Διαδραστικό AI quiz-παιχνίδι για την Ε' Δημοτικού, που φτιάχνει ερωτήσεις
**ζωντανά από τα πραγματικά σχολικά βιβλία**.

Python + Streamlit + OpenAI (GPT-4o-mini + DALL·E) + gTTS + Folium.

## ✨ Τι κάνει

- 🤖 **Multi-agent**: πράκτορες διαβάζουν το βιβλίο (RAG), φτιάχνουν ερώτηση,
  διαλέγουν μορφή και ζωγραφίζουν εικόνα — όλα ζωντανά.
- 📚 **4 μαθήματα** από τα επίσημα βιβλία: Γεωγραφία, Ιστορία, Φυσικά, Μαθηματικά.
- 🗺️ **Διαδραστικός χάρτης** (κλικ στο σημείο), 📅 χρονογραμμή, 🔢 αριθμογραμμή, 🔘 κουμπιά.
- 🎨 **Εικόνες DALL·E** φτιαγμένες για κάθε ερώτηση.
- 🎮 Πόντοι, σερί 🔥, ζωές ❤️, αστέρια, παράσημα.
- 🔊 Ελληνική φωνή (gTTS) · 💡 Υποδείξεις + εξήγηση.
- 🏆 Πίνακας ρεκόρ.

## 📁 Αρχεία

| Αρχείο | Τι είναι |
|---|---|
| `app.py` | Η εφαρμογή (UI, παιχνίδι, renderers) |
| `agents.py` | Οι πράκτορες (retrieval, ερώτηση, μορφή, εικόνα, δάσκαλος) |
| `knowledge_base.json` | Η ύλη από τα 4 βιβλία (έτοιμη — 728 KB) |
| `requirements.txt` | Βιβλιοθήκες |
| `ingest.py` | (προαιρετικό) ξαναφτιάχνει τη ΒΓ από νέα PDF |

## 🚀 Εγκατάσταση

```bash
cd Family_App
pip install -r requirements.txt
```

Βάλε το OpenAI key στο `.streamlit/secrets.toml`:
```toml
OPENAI_API_KEY = "sk-..."
```

Τρέξε:
```bash
streamlit run app.py
```

## 🌍 Γεωγραφία Εξερευνητής

Ξεχωριστή εφαρμογή μόνο για τη Γεωγραφία, που λειτουργεί και χωρίς OpenAI key:

```bash
streamlit run geo_app.py
```

- 🦉 Η Σοφούλα η κουκουβάγια οδηγεί το παιδί σε όλη την ύλη, με κάρτες γνώσης και χάρτες.
- 🎮 5 παιχνίδια: Ζεστά-Κρύα, Κυνήγι Πυξίδας, Ποιο είναι πιο...;, Μνήμη, Ταξίδι με Αερόστατο.
- 🎯 Αποστολή της ημέρας και 🔁 εξάσκηση στα λάθη.
- 🏅 Προφίλ ανά παιδί με XP, επίπεδα, αστέρια και παράσημα (`geo_profiles.json`, `geo_badges.json`).

Οι χάρτες και η φωνή χρειάζονται σύνδεση στο ίντερνετ.

## 💰 Κόστος

- Ερωτήσεις (GPT-4o-mini): κλάσματα του σεντ.
- Εικόνες (DALL·E 3): ~4 σεντς η καθεμία. Κλείσε τις από τον διακόπτη
  «🎨 Εικόνες DALL·E» στο μενού αν θες μηδενικό κόστος.

## 🔄 Προσθήκη νέας ύλης

Βάλε νέα PDF και τρέξε το `ingest.py` (άλλαξε τις διαδρομές μέσα του)
για να ξαναφτιαχτεί το `knowledge_base.json`.
